# Реализация алгоритма хеширования ГОСТ Р 34.11-2012 (Стрибог)
Ветка: `debug`

## Обзор
Данная ветка содержит отладочную реализацию алгоритма хеширования ГОСТ Р 34.11-2012 ("Стрибог"). Код ориентирован на максимальную прозрачность работы алгоритма — все внутренние преобразования выводятся в консоль, что позволяет отслеживать каждый шаг вычислений.

*Ссылки на другие ветки*:
* master — чистая реализация без отладочного вывода.
* optimized — оптимизированная версия с использованием SIMD.

## Система сборки
Проект использует несколько `Makefile` для разных целей:

### Основной Makefile (корневой)
```bash
# Сборка в режиме отладки (по умолчанию)
make

# Или явно указать режим
make debug

# Сборка в релизном режиме
make release

# Запуск тестов на примерах из ГОСТ
make test

# Запуск сравнения с другими реализациями
make compare

# Запуск тестов производительности
make benchmark
```
